# 🏗️ Детектор дефектов бетонных конструкций (MVP)

Прототип веб-приложения для автоматического обнаружения дефектов бетонных
конструкций (трещин, сколов, высолов, раковин) по фотографии. Использует
готовую предобученную модель через **Roboflow Inference API**, поэтому не
требует собственного обучения модели.

## 📦 Стек технологий

- Python 3.10+
- Streamlit — веб-интерфейс
- OpenCV, Pillow, NumPy — обработка и отрисовка изображений
- Roboflow Inference SDK — обращение к готовой модели детекции

## 📁 Структура проекта

```
.
├── app.py               # Streamlit-приложение (UI)
├── detector.py           # Класс RoboflowDetector — логика API и визуализация
├── requirements.txt      # Зависимости проекта
├── Procfile              # Команда запуска для Railway
├── .gitignore            # Исключения для git (venv, кэш и т.п.)
└── README.md             # Эта инструкция
```

## 🚀 Установка и запуск

### 1. Клонируйте/скопируйте файлы проекта в отдельную папку

```bash
mkdir defect-detector-mvp
cd defect-detector-mvp
# поместите сюда app.py, detector.py, requirements.txt
```

### 2. Создайте и активируйте виртуальное окружение

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Получите API-ключ Roboflow

1. Зарегистрируйтесь на [roboflow.com](https://roboflow.com).
2. Перейдите в настройки рабочей области (**Workspace Settings**).
3. Скопируйте значение **Private API Key** во вкладке *Roboflow API*.
4. При необходимости найдите готовую модель детекции трещин/дефектов
   бетона в [Roboflow Universe](https://universe.roboflow.com) и укажите
   её `model_id` (формат `project-slug/version`) в боковой панели приложения.

### 5. Запустите приложение

```bash
streamlit run app.py
```

После запуска приложение откроется в браузере по адресу
`http://localhost:8501`.

### 6. Использование

1. Введите API-ключ Roboflow в боковой панели.
2. При необходимости укажите ID модели и настройте порог уверенности.
3. Загрузите фотографию конструкции (JPG/JPEG/PNG).
4. Нажмите кнопку **«Запустить анализ»**.
5. Изучите результаты: сравнение фото до/после, метрики, детализацию по
   каждому дефекту и скачайте JSON с результатами.

## ⚠️ Примечания

- Это MVP-прототип для демонстрации инвесторам/клиентам — обработка
  ошибок сети и авторизации реализована, но для production рекомендуется
  добавить логирование, кэширование и обработку больших изображений.
- Модель `concrete-crack-detection/1`, указанная по умолчанию, — это
  плейсхолдер; для реального использования подберите подходящую модель
  в Roboflow Universe под ваш тип дефектов.

## ☁️ Деплой на Railway

Проект уже содержит `Procfile`, поэтому деплой не требует ручной настройки
команды запуска.

### 1. Подготовьте репозиторий

Убедитесь, что в git-репозиторий попадают только эти файлы (папка `venv/`
исключена через `.gitignore`):

```
app.py
detector.py
requirements.txt
Procfile
.gitignore
README.md
```

Запушьте репозиторий на GitHub:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <ссылка-на-ваш-репозиторий>
git push -u origin main
```

### 2. Создайте проект на Railway

1. Зайдите на [railway.app](https://railway.app) и войдите (можно через GitHub).
2. Нажмите **New Project → Deploy from GitHub repo** и выберите этот репозиторий.
3. Railway автоматически определит Python-проект, установит зависимости из
   `requirements.txt` и запустит команду из `Procfile`.

### 3. Проверьте переменную порта

`Procfile` уже использует переменную окружения `$PORT`, которую Railway
подставляет автоматически (`--server.port $PORT --server.address 0.0.0.0`).
Менять эту команду вручную не нужно.

### 4. (Опционально) API-ключ Roboflow как переменная окружения

По умолчанию пользователь вводит API-ключ прямо в интерфейсе приложения —
это работает и после деплоя без дополнительных настроек. Если вместо этого
вы хотите зашить ключ по умолчанию для собственного тестирования:

1. В Railway откройте **Variables** и добавьте `ROBOFLOW_API_KEY` со
   значением вашего ключа.
2. Ключ Roboflow **не должен** попадать в код или в git — используйте
   только переменные окружения.

### 5. Откройте приложение

После завершения деплоя Railway выдаст публичный URL вида
`https://<ваш-проект>.up.railway.app` — приложение будет доступно по нему.
